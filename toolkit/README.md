# Toolkit

This folder contains a set of utility scripts designed to simplify and automate certain steps of the **Nextflow** workflow, particularly for preparing the databases used by **MMseqs2** in the **LAGOON-MCL** pipeline.

## Directory Contents

The toolkit includes:

- `build_databases.py`: the main script used to download and build the required databases.
- `bin/`: internal scripts called by the `build_*.sh` scripts.
- `scripts/`: modular and reusable Python and Bash scripts for specific tasks (file processing, analyses, cluster execution, etc.).

## Structure

```
toolkit/
├── bin/                                # Scripts internes utilisés par build_*.sh
├── scripts/                            # Scripts utilitaires réutilisables (Python, Bash)
│  ├── json_to_matrix.py                #
│  ├── convert_annotation_file.py       #
│  ├── extract_clusters_informations.py #
│  └── run_slurm.sh                     #
└── build_databases.sh                  # Script principal utilisant les scripts de bin/
```

## Requirements

The following tools are required to use this toolkit:

- **MMseqs2** (version 15.6f452)
- **Python** ≥ 3.12, with the following libraries:
    - Matplotlib
    - Pandas
    - python-igraph

An `environment.yml` file is provided to automatically create a [**Conda** or **Mamba**](https://github.com/conda-forge/miniforge) environment containing all required dependencies.

### Installation

1. Install [**Conda** or **Mamba**](https://github.com/conda-forge/miniforge).

2. Create the environment from the `environment.yml` file:

```sh
conda env create -f environment.yml
```

3. Activate the environment:

```sh
conda activate toolkit
```

## Usage

### Building Databases

The [**Pfam**]() and [**AlphaFold Clusters**]() databases are used by [**MMseqs2**]() in the LAGOON-MCL workflow to annotate and enrich information associated with sequences (more information [here]()).

```sh
python build_database.py -d [database]
```

**Available Options**
- `-d / --databases`: select the database(s) to install
    - `pfam`: download and build the Pfam database for MMseqs2
    - `alphafold`: download and build the AlphaFold Clusters database for MMseqs2
    - `all`: download and build both Pfam and AlphaFold Clusters databases

> The LAGOON-MCL workflow requires the AlphaFold Clusters database to function correctly.

To use the databases generated by this toolkit, the appropriate parameters must be provided when running LAGOON-MCL.

**Pfam Database**

Required parameters:
- `--pfamDB /path/to/database/pfamDB`: path to the Pfam database
- `--pfamDB_name pfamDB`: name of the database

**AlphaFold Clusters Database**

Required parameters:
- `--alphafoldDB /path/to/database/alphafoldDB`: path to the AlphaFold Clusters database
- `--alphafoldDB_name alphafoldDB`: name of the database
- `--uniprot /path/to/database/uniprot_function.json`: Pfam annotations linked to sequence identifiers in the AlphaFold Clusters database (available from the InterPro database)

**Database Location**

All databases generated by this toolkit are available in the following directory:

```pgsql
database/
```
